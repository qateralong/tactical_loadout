# Tactical Camo Armor

Bullet-resistant tactical armor for [TaCZ](https://modrinth.com/mod/tacz-1.21.1) on NeoForge 1.21.1.

- Sets: CS2-style CT and T, US Woodland (M81), US Desert (DCU), US Green (OD).
- Pieces: helmet, plate carrier, leggings with knee pads, boots; light, medium and heavy tiers.
- Per-zone bullet protection (head, body, legs, feet) and durability loss on hit.
- Full US sets reduce the distance at which mobs notice you.

## Requirements

- Minecraft 1.21.1, NeoForge 21.1.x, Java 21
- GeckoLib 4.9+
- TaCZ NeoForge port 1.1.8+

## Building

```
./gradlew runData build
```

The jar is written to `build/libs`.
